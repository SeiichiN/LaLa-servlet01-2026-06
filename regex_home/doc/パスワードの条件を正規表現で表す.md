javaで、正規表現の勉強をしています。
ブラウザのフォームから、パスワードが送られてきたとして、
そのパスワードが、
「半角８文字以上で、半角英数字記号が含まれていて、英字も大文字と小文字があること」
という条件をつけていたとすると、それを検証する正規表現パターンはどうなるでしょうか？

Pattern PASSWORD_PATTERN = 
			Pattern.compile("(\\d|[a-z]|[A-Z]|[!@#\\$%\\^&\\*()_]){4,8}");
			
このパターンだと、「数字大文字小文字記号のどれかを含んでいればよい」になって
しまいます。

---

おっしゃる通りです。

```java
Pattern.compile("(\\d|[a-z]|[A-Z]|[!@#\\$%\\^&\\*()_]){8,}");
```

だと、

* 数字、英小文字、英大文字、記号の**いずれか**
* を8文字以上繰り返す

という意味になります。

例えば、

```text
aaaaaaaa
11111111
!!!!!!!!
```

もすべてマッチしてしまいます。

---

## 要件の整理

> 半角8文字以上で、半角英数字記号が含まれていて、英字も大文字と小文字があること

これを分解すると、

1. 半角文字のみ
2. 8文字以上
3. 小文字を1文字以上含む
4. 大文字を1文字以上含む
5. 数字を1文字以上含む
6. 記号を1文字以上含む

になります。

このような「○○を含む」は、**先読み（lookahead）**を使うのが定番です。

---

## 正規表現

```java
Pattern PASSWORD_PATTERN =
    Pattern.compile(
        "^(?=.*[a-z])(?=.*[A-Z])(?=.*\\d)(?=.*[!@#$%^&*()_])[A-Za-z\\d!@#$%^&*()_]{8,}$"
    );
```

### 各部分の意味

#### ① 先頭

```regex
^
```

文字列の先頭。

---

#### ② 小文字を含む

```regex
(?=.*[a-z])
```

* `.*` : 任意の文字を0文字以上
* `[a-z]` : 小文字1文字

つまり、

> どこかに小文字が1文字以上ある

という意味です。

---

#### ③ 大文字を含む

```regex
(?=.*[A-Z])
```

---

#### ④ 数字を含む

```regex
(?=.*\d)
```

---

#### ⑤ 記号を含む

```regex
(?=.*[!@#$%^&*()_])
```

---

#### ⑥ 使用できる文字と長さ

```regex
[A-Za-z\d!@#$%^&*()_]{8,}
```

* 英大文字
* 英小文字
* 数字
* 指定した記号

のみを許可し、それが8文字以上。

---

## マッチ例

### OK

```text
Abc123!@
Password1_
A1b2C3!@
```

### NG

```text
password1!    // 大文字なし
PASSWORD1!    // 小文字なし
Password!!    // 数字なし
Password1     // 記号なし
Ab1!あいうえお // 全角文字あり
```

---

## Javaコード例

```java
private static final Pattern PASSWORD_PATTERN =
    Pattern.compile(
        "^(?=.*[a-z])(?=.*[A-Z])(?=.*\\d)(?=.*[!@#$%^&*()_])[A-Za-z\\d!@#$%^&*()_]{8,}$"
    );

public static boolean isValidPassword(String password) {
    return PASSWORD_PATTERN.matcher(password).matches();
}
```

---

なお、実務では記号を個別に列挙するより、

```regex
(?=.*[^A-Za-z0-9])
```

のように、

> 英数字以外の半角文字を1文字以上含む

と書くことも多いです。ただし、この書き方だとスペースや日本語記号まで許可してしまう場合があるので、**許可する記号を明示的に列挙する現在の書き方のほうが安全**です。
